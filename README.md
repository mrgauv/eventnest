# EventNest – Local Event Discovery Platform

**Live site:** https://mrgauvi.github.io/eventnest/

**Team:** Zero Seven | **Course:** CSE326 | Lovely Professional University, Phagwara

## Problem statement
Local event details are scattered over posters and chat groups, so people miss events and organisers cannot track registrations. EventNest is a role-based event discovery platform where users browse, search and register for events, and admins manage events and approve registrations.

## Features
- Login and sign up with validation, two roles: user and admin
- Browse events, search by title or venue, filter by category
- One-click registration with status tracking (Pending, Confirmed, Rejected)
- Admin dashboard: add, edit and delete events, approve or reject registrations, summary cards
- Seat limits, confirmation messages, responsive layout
- 3D home page (CSS 3D cube and a three.js scene) and a live countdown to the next event

## Technologies
HTML5, CSS3 (including 3D transforms), JavaScript, three.js. Data is stored in the browser with localStorage, so there is no backend.
